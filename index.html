⚙️ Настройки

Токен — то, что Мишка запомнил при сопряжении (PAIR). При подключении пульт шлёт AUTH <токен>.

Для PAIR: нажми кнопку и в течение ~20 секунд одновременно зажми обе нижние лапы Мишки. Старое сопряжение (с официальным приложением) при этом заменится.

Список дня берётся из каталога по дню недели на этом телефоне или компьютере. Можно поправить вручную на сегодня; на следующую дату снова подставится каталог.

Избранное на Мишке

По умолчанию выкл. Звезда меняет только список в пульте. Если включить — при нажатии звезды пульт также добавит/уберёт сказку в избранное Мишки (лапа «звезда»). Лимит на устройстве: 3 без подписки / 10 с подпиской. Список с Мишки (FLST) читается всегда при подключении.

Названия сказок

Только для отображения в пульте — Мишке всегда уходит числовой id.

Перенос на iPhone: «Копировать JSON» → отправь себе текст → в Bluefy вставь его в поле ниже и нажми «Импорт». В экспорт входят названия, избранное пульта и недавние.

Метки

Свои ярлыки к сказкам (например «Про животных»). Редактируются вместе с названием по ✏️.
